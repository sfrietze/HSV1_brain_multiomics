# GeoMx WTA spatial transcriptomics analysis

The GeoMx WTA analysis used in Figure 5 was generated from the ROI-level DCC data deposited under GEO accession GSE324176.

## ROI filtering

GEO contains 47 ROI samples. Four of these ROIs were excluded from the downstream transcriptomic analysis by the filtering criteria implemented in `Figure5_00_build_GeoMx.R`:

- `DSP-1001660019915-A-A01.dcc`: failed segment-level QC because of low stitched reads and low alignment.
- `DSP-1001660019915-A-D09.dcc`: failed segment-level QC because of low stitched reads.
- `DSP-1001660019915-A-D01.dcc`: excluded by the gene-detection filter (493 genes detected; detection rate 0.02469569, below the 0.025 threshold).
- `DSP-1001660019915-A-D10.dcc`: excluded by the gene-detection filter (478 genes detected; detection rate 0.02394430, below the 0.025 threshold).

The resulting analysis dataset therefore contains 43 ROIs: 35 HSV-1 antigen-negative and 8 HSV-1 antigen-positive ROIs.

The analysis-ready expression matrix and matching ROI metadata are:

- `GSE324176_GeoMx_WTA_gene_expression_matrix_QCfiltered_43ROIs.csv.gz`
- `GSE324176_GeoMx_WTA_ROI_metadata_QCfiltered_43ROIs.csv.gz`

These files contain the same 43 ROIs, in the same order, and are regenerated by `Figure5_00_build_GeoMx.R`.
